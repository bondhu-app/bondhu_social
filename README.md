# বন্ধু সোশ্যাল

বন্ধু সোশ্যাল একটি আধুনিক Social Media Application, যা Flutter এবং Firebase ব্যবহার করে তৈরি করা হচ্ছে।

## App Name

বন্ধু সোশ্যাল

## Project Name

bondhu_social

## Technology

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Google Sign-In

## Features

- User Registration
- User Login
- Google Sign-In
- Profile
- Create Post
- Photo Post
- Like
- Comment
- Share
- Friends
- Follow
- Messenger
- Notifications
- Privacy Settings
- Admin Dashboard
