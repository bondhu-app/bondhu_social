# My App

A Flutter application powered by Firebase.

## Features

- User Authentication
- Google Sign-In
- Cloud Firestore
- Firebase Storage
- Firebase Cloud Messaging

## Getting Started

1. Install Flutter.
2. Run `flutter pub get`.
3. Configure Firebase.
4. Run the app with `flutter run`.

## Project Structure

- `lib/main.dart` — App entry point
- `lib/firebase_options.dart` — Firebase configuration
- `lib/services/auth_service.dart` — Authentication
- `lib/services/data_service.dart` — Database operations
